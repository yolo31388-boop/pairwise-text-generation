# 游戏内自然语言生成与文本生成系统

## 项目描述

游戏内自然语言生成与文本生成系统的bug修复项目。核心模块 `nlp/text_generation.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 文本生成完全没做不能生成文本
- 语言模型完全没做只能做简单的字符拼接
- N-gram完全没做不能用N-gram模型
- 文本摘要完全没做不能生成摘要
- 文本分类完全没做不能分类文本

## 运行测试

```bash
python -m pytest tests/test_text_generation.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
